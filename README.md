# My music analyzer 

## Overview
My Music Analyzer is a Python project that analyzes Spotify listening history to better understand their listening habits. 

## Features
- Reads Spotify data from JSON files
- Cleans records before analyzing them
- Calculates listening statistics
- Identifies top artists and songs
- Analyzes listening time and patterns
- Displays results through a easy to understand, browser-based interface 

## How it works 
Spotify tracks their users data in JSON files. The Python code loads those files and cleans the data, making sure each record contains
- artist name
- track name
- listening timestamp
- milliseconds played
